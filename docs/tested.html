Guide · What’s tested

What we’ve checked for real, and what we haven’t.

T.R.I.S.T.A.N. is an early release. Everything below has automated tests. This table shows which parts have also run against the real thing.

Tested with the real service, or with stand-ins only
PartStatusNotes
Claude CodeTested for realApprovals on every action, and two sessions running at once.
Copilot, two sessions in Auto modeTested for realEach session wrote its own file in its own folder, at the same time.
Copilot in Ask modeStand-in onlyIt needs blanket permission, so we haven’t run it live. Issue 5
Amazon BedrockStand-in onlyRequest signing matches Amazon’s published examples. Issue 1
Azure OpenAI on the MacTested for realStreaming and tool calls worked against a real deployment, signed in with an API key.
Azure OpenAI with Azure CLI sign-in, and on iPhoneStand-in onlyEntra ID sign-in and the phone’s standalone mode are not yet tried live. Issue 2
Ollama and kids-mode local answersStand-in onlyThe routing, the refusal and the one-time parent approval are tested with a scripted model. We haven’t run it against a real local model yet.
Offline fallback to OllamaTested for realWith the Wi-Fi off, a cloud mission ran on the local model and the note showed. Starting a stopped Ollama is covered by tests and a manual run of the script, but we haven’t watched the whole flow in the app. How it works
Session memoryStand-in onlyTested with scripted models; not yet tried live across several real missions.
Kids safe mode and the quiet microphoneStand-in onlyThe PIN lock, the relock and the microphone rules are tested, and the PIN screen is in the demo video. Unlocking with Touch ID or the Mac password has not been tried live.
iPhone and iPad appSimulator onlyThe secure link is tested end to end on one machine. Not yet on a real phone. Issue 3
Windows terminal versionWindows CI onlyReleased in 0.6.1 as an installer and a zip. Built and tested on Windows Server 2025 in GitHub Actions, against fake provider CLIs and a mocked Ollama. The 0.7.1 zip has been run once, by hand, on Windows 11 for ARM64 in a virtual machine (version, providers and help, under x64 emulation); the installer has not been run on a Windows 10 or 11 desktop, and no provider has run against a live account on Windows. What is verified
Voice, wake word, notifications, SpotifyStand-in onlyThe logic is tested; nobody has used them end to end yet. Issue 4

A few limits to know about: the Mac download is for Apple Silicon only and isn’t notarized yet, the Windows download is a terminal version, as an installer or a zip (x64 only, not code-signed), and iPhone approvals only arrive while the app is open in front.
