An estimate, not a promise. Sizes come from what similar changes cost to build with Claude Code. A point is a best guess; the real number could be half or double. Dollars are at Claude API list prices on Opus 5.5, about $0.56 per million tokens, and this counts tokens, not calendar time. Small is under 5M tokens, medium 5 to 20M, large 20 to 40M. Three umbrella issues (the whole backlog, Windows support and the Windows app epic) are left out so nothing is counted twice. Each issue also carries the estimate as a comment.
