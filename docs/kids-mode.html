Guide

Safe for kids, and private.

Kids safe mode keeps a child’s questions on your Mac, asks a parent before anything leaves it, and speaks in a friendlier voice.

What it does

Switch it on in Configuration > KIDS SAFE MODE. While it is on:

  • Questions stay on the Mac. Every question goes to a local Ollama model, whichever provider is selected.
  • Settings need a parent. Opening Settings asks for a PIN, or Touch ID or the Mac password.
  • Yolo and Auto are off. The mode goes back to Ask whenever it locks.
  • It locks itself again when Settings close or after five minutes.
  • Phones cannot change it. A paired iPhone cannot turn the mode off.
  • A brighter voice. T.R.I.S.T.A.N. speaks with the Samantha voice, lifted a little in pitch and a touch slower, and uses friendlier lines such as “Ready! Let’s go!” and “We did it! Hooray!” The built-in Samantha is a basic voice; for the cleanest sound run scripts/install-voices.sh en_US and download Samantha (Enhanced).

When the local model is not available

If Ollama is not running or has no model, nothing is sent anywhere. The child sees “Please ask a parent.” Then:

  1. A parent is asked, by PIN or Touch ID or the Mac password, whether this one question may go to the selected cloud provider. If Ollama itself was selected, the cloud answer goes to Claude.
  2. Approving does not unlock kids mode. The very next question is local again.
  3. Cancelling keeps the question off the cloud.

The parent lock

  • PIN: four or more digits, stored hashed in your Keychain.
  • Touch ID / Mac password: whichever you choose. If kids mode is on with the PIN method but no PIN is stored (for example after clearing the Keychain), T.R.I.S.T.A.N. falls back to the Mac’s own login.
  • Not a content filter. The lock controls what a child can change and where questions go. It does not yet screen what the model says.

The voice

T.R.I.S.T.A.N. uses the macOS voice Samantha, lifted a little in pitch and a touch slower; if she is not installed it falls back to another friendly American voice. The basic Samantha can sound rough, so for the cleanest sound run scripts/install-voices.sh en_US and download Samantha (Enhanced): it is picked up automatically. An earlier version used the child-like “Junior” voice pushed up 30%, which was squeaky and crackled (see the crackle report). It does not imitate any TV character. Add voices in System Settings > Accessibility > Spoken Content > System Voice > Manage Voices.

What is and isn’t done

  • Done and tested with stand-ins: the local-only routing, the refusal, the one-time parent approval, the lock and relock, and the microphone rules.
  • Not tried live: a full kids session on a real local model, and unlocking with Touch ID or the Mac password.
  • Not built yet: a child-safe system prompt for the local model and screening of its answers before they are shown. These are the next steps.

On Windows the tristan kids commands use the same setting and parent PIN, and only Ollama answers while kids mode is on. There is no Touch ID or Windows Hello there: the PIN is the only unlock, and the terminal version has no voice. See Kids mode on Windows, including its honest limits.
