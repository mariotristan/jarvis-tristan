Guide

Up and running in a few minutes.

Download the app or build it yourself, then pick DEMO and watch it work. No accounts needed.

Requirements

  • macOS 14 or later on an Apple Silicon Mac. The release is built for arm64 only. Intel Macs: build from source (untested).
  • To build from source: the full Xcode, not just the command line tools, because SwiftUI’s macros need the full toolchain. scripts/bundle.sh finds /Applications/Xcode.app even if xcode-select points elsewhere.
  • For the Claude provider: the Claude Code CLI, installed and signed in.
  • Nothing else to try it: pick DEMO and type any task.
  • On Windows 10 or 11 (x64): there is no app, but there is a tristan terminal command, released in 0.6.1 as an installer and a zip. CI has so far run it only on Windows Server 2025. See Windows below.

From a release

  1. Download Tristan-0.7.1.dmg from the latest release.
  2. Open the disk image and drag T.R.I.S.T.A.N. into Applications. Or use Terminal, below.
  3. Remove the download warning, once. macOS flags apps from the internet, and T.R.I.S.T.A.N. is not notarized yet (that needs a paid Apple account).
  4. Open T.R.I.S.T.A.N. Look for the pill at the camera notch, the icon in the menu bar, or press ⌥ Space. T.R.I.S.T.A.N. has no Dock icon.
# 1. Optional: check the download
cd ~/Downloads && shasum -a 256 -c Tristan-0.7.1.dmg.sha256

# 2. Install
hdiutil attach Tristan-0.7.1.dmg
cp -R "/Volumes/Tristan 0.7.1/Tristan.app" /Applications/

# 3. Remove the quarantine flag
xattr -dr com.apple.quarantine /Applications/Tristan.app

# 4. Open it
open /Applications/Tristan.app

If you skip step 3, macOS says the app “cannot be opened”. You can also allow it under System Settings > Privacy & Security > Open Anyway.

From source

git clone https://github.com/mariotristan/jarvis-tristan.git
cd jarvis-tristan
scripts/install.sh      # builds, copies Tristan.app into /Applications and launches it

Or build without installing:

scripts/bundle.sh      # a release build wrapped into Tristan.app, with icon and version
open Tristan.app

# a quick debug build, no app bundle
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift build

# the tests
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test

Maintainers: scripts/make-dmg.sh builds the disk image, and git tag vX.Y.Z && git push origin vX.Y.Z publishes a release. See docs/ci-and-release.md.

Windows: the tristan command

On Windows, T.R.I.S.T.A.N. is a terminal command, not a window. You run a mission on any of the five providers and answer each approval in Windows Terminal, PowerShell or cmd. It is released as 0.6.1, as an installer (recommended) and as a portable zip. It is built and tested on Windows Server 2025 in CI, but it has not been run on a real Windows 10 or 11 desktop, and no provider has run against a live account on Windows. The installer is not code-signed, so Windows SmartScreen may warn when you run it (we have not seen what it shows on a real desktop). In CI only silent installs were tried; nobody has gone through the wizard screens. MSIX, winget and code signing are on the roadmap.

Download for Windows

The installer

  1. Download Tristan-0.7.1-windows-x64-setup.exe and Tristan-0.7.1-windows-x64-setup.exe.sha256 from the latest release.
  2. Check it with Get-FileHash -Algorithm SHA256 against the hash in the .sha256 file (upper or lower case does not matter).
  3. Run it. If SmartScreen warns, that is the missing code signature. By default it installs for you alone, into %LocalAppData%\Programs\Tristan, without administrator rights. Choose all users in the dialog (or pass /ALLUSERS) to install for everyone.
  4. Leave “Add Tristan to my PATH” ticked. Uninstalling removes the entry again. It installs exactly the files that are in the zip: tristan.exe, the Swift runtime DLLs and the licence notices.
  5. Try it in a new terminal window. tristan --version prints 0.7.1, and tristan providers shows which providers are ready.
# PowerShell
cd ~\Downloads
(Get-FileHash -Algorithm SHA256 Tristan-0.7.1-windows-x64-setup.exe).Hash
Get-Content Tristan-0.7.1-windows-x64-setup.exe.sha256
.\Tristan-0.7.1-windows-x64-setup.exe
# then, in a new terminal window:
tristan --version
tristan providers
tristan run --provider ollama "add a README"

Silent install, for scripts (the switches are /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /CURRENTUSER or /ALLUSERS, /DIR="...", /TASKS="addtopath" and /LOG="..."):

.\Tristan-0.7.1-windows-x64-setup.exe /VERYSILENT /CURRENTUSER /TASKS="addtopath"

Uninstall in Settings, Apps (or Add or remove programs). Your settings and history in %APPDATA%\Tristan and your stored secrets in Credential Manager are kept. To remove them too, delete %APPDATA%\Tristan and run tristan secret delete azure-openai-key (and the same for any other key you stored) before you uninstall.

Portable, no install: the zip

  1. Download Tristan-0.7.1-windows-x64.zip and Tristan-0.7.1-windows-x64.zip.sha256 from the latest release, and check it the same way.
  2. Extract it to a folder and add that folder to your PATH. The zip holds tristan.exe, the Swift runtime and Foundation DLLs, ICU, the Visual C++ runtime DLLs and the licence notices (23 files, about 80 MB unpacked).
  3. Try it. tristan --version prints 0.7.1.
cd ~\Downloads
(Get-FileHash -Algorithm SHA256 Tristan-0.7.1-windows-x64.zip).Hash
Get-Content Tristan-0.7.1-windows-x64.zip.sha256
Expand-Archive Tristan-0.7.1-windows-x64.zip -DestinationPath $HOME\Tristan
$env:Path += ";$HOME\Tristan"      # this window only; add the folder to PATH in Settings to keep it
tristan --version
tristan providers

The Windows guide covers setting up each provider with tristan config and tristan secret, approvals, kids mode, building from source, what is verified and what is not, and how it was built.

Uninstall, and removing test versions

One script removes the app and it shows what it will remove before it does anything.

scripts/uninstall.sh --dry-run            # only list what would be removed
scripts/uninstall.sh                      # quit and remove installed copies and mounted disk images
scripts/uninstall.sh --purge --build      # also settings, history, Keychain items and build output
  • Installed copies. Applications, your own Applications folder and any other copy Spotlight finds, only when it really is this app. Settings and history are kept unless you add --purge.
  • Purge. Removes preferences, history, caches, saved window state, the pairing secret and API keys in the Keychain, and leftovers from the test suite.
  • Not touched. Ollama and its models, installed voices and the source checkout. If Launch at login was on, also remove it under System Settings > General > Login Items.

The scripts

Everything in the scripts folder
ScriptWhat it does
scripts/install.shBuilds from source, installs into Applications and launches.
scripts/bundle.shBuilds a release binary and wraps it into Tristan.app.
scripts/make-dmg.shBuilds dist/Tristan-<version>.dmg and a checksum next to it.
scripts/setup-ollama.shInstalls and starts Ollama and pulls a model. With --start-only it only starts an installed Ollama (the app runs this for the offline fallback). See Local models.
scripts/setup-ollama.ps1Windows: checks for Ollama (with a winget hint if it is missing), starts it, pulls a model and sets it for tristan. With -StartOnly it only starts an installed Ollama. See Windows.
scripts/package-windows.ps1Windows: builds tristan.exe and writes dist\Tristan-<version>-windows-x64.zip with its DLLs, licence notices and a checksum; scripts/package-windows-installer.ps1 then builds Tristan-<version>-windows-x64-setup.exe from the same files. See Windows.
scripts/install-voices.shOpens System Settings so you can download an Enhanced voice, waits for it and plays a sample. Fixes crackly speech. See the crackle report.
scripts/uninstall.shQuits the app and removes installed copies and mounted disk images. --purge also removes settings, history and Keychain items, --build removes build output, --dry-run only lists.
scripts/record-demo.shFilms the built-in demo (Tristan --demo) for the videos: the window and the app’s own sound, via scripts/record-window.swift.
scripts/ios-demo.shRuns the iPhone or iPad app in the simulator against a demo Mac.
scripts/ios-icon.shRegenerates the iOS app icon.

First run

  1. Pick a provider along the bottom. Start with DEMO to see everything move.
  2. Click the folder button to choose the project folder.
  3. Type a task and press Return or click EXECUTE.
  4. Approve or deny when asked, in the window or from the notch.
  5. Watch the mission log and code stream. Click ABORT to stop a run.

Shortcuts: ⌥ Space opens the window, ⌥ ⇧ Space held is push-to-talk, ⌘T opens a new session, ⌘1…⌘9 switch, ⌘W closes.
