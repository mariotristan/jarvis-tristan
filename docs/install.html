Guide

Up and running in a few minutes.

Download the app or build it yourself, then pick DEMO and watch it work. No accounts needed.

Requirements

  • macOS 14 or later on an Apple Silicon Mac. The release is built for arm64 only. Intel Macs: build from source (untested).
  • To build from source: the full Xcode, not just the command line tools, because SwiftUI’s macros need the full toolchain. scripts/bundle.sh finds /Applications/Xcode.app even if xcode-select points elsewhere.
  • For the Claude provider: the Claude Code CLI, installed and signed in.
  • Nothing else to try it: pick DEMO and type any task.

From a release

  1. Download Tristan-0.5.0.dmg from the latest release.
  2. Open the disk image and drag Tristan into Applications. Or use Terminal, below.
  3. Remove the download warning, once. macOS flags apps from the internet, and Tristan is not notarized yet (that needs a paid Apple account).
  4. Open Tristan. Look for the pill at the camera notch, the icon in the menu bar, or press ⌥ Space. Tristan has no Dock icon.
# 1. Optional: check the download
cd ~/Downloads && shasum -a 256 -c Tristan-0.5.0.dmg.sha256

# 2. Install
hdiutil attach Tristan-0.5.0.dmg
cp -R "/Volumes/Tristan 0.5.0/Tristan.app" /Applications/

# 3. Remove the quarantine flag
xattr -dr com.apple.quarantine /Applications/Tristan.app

# 4. Open it
open /Applications/Tristan.app

If you skip step 3, macOS says the app “cannot be opened”. You can also allow it under System Settings > Privacy & Security > Open Anyway.

From source

git clone https://github.com/mariotristan/jarvis-tristan.git
cd jarvis-tristan
scripts/install.sh      # builds, copies Tristan.app into /Applications and launches it

Or build without installing:

scripts/bundle.sh      # a release build wrapped into Tristan.app, with icon and version
open Tristan.app

# a quick debug build, no app bundle
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift build

# the tests
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test

Maintainers: scripts/make-dmg.sh builds the disk image, and git tag vX.Y.Z && git push origin vX.Y.Z publishes a release. See docs/ci-and-release.md.

The scripts

Everything in the scripts folder
ScriptWhat it does
scripts/install.shBuilds from source, installs into Applications and launches.
scripts/bundle.shBuilds a release binary and wraps it into Tristan.app.
scripts/make-dmg.shBuilds dist/Tristan-<version>.dmg and a checksum next to it.
scripts/setup-ollama.shInstalls and starts Ollama and pulls a model. See Local models.
scripts/record-demo.shFilms the built-in demo (Tristan --demo) for the videos.
scripts/ios-demo.shRuns the iPhone or iPad app in the simulator against a demo Mac.
scripts/ios-icon.shRegenerates the iOS app icon.

First run

  1. Pick a provider along the bottom. Start with DEMO to see everything move.
  2. Click the folder button to choose the project folder.
  3. Type a task and press Return or click EXECUTE.
  4. Approve or deny when asked, in the window or from the notch.
  5. Watch the mission log and code stream. Click ABORT to stop a run.

Shortcuts: ⌥ Space opens the window, ⌥ ⇧ Space held is push-to-talk, ⌘T opens a new session, ⌘1…⌘9 switch, ⌘W closes.
